# SafeLex — англо-український словник рятувальника

**Застосунок для телефона** (Android та iPhone): пошук термінів, довідник за темами, квіз і флеш-картки. База — 3353 терміни з пожежної безпеки (Словник Шуневича 2016).
Встановлюється на екран телефона з власною іконкою, відкривається на весь екран без адресного рядка
і повністю працює без інтернету. Розробка: кафедра іноземних мов та перекладознавства ЛДУ БЖД.

**Розробники:** Зелінський Гліб Сергійович — курсант 3 курсу; Пальчевська Олександра Святославівна — доцент кафедри іноземних мов та перекладознавства.
(Змінити підписи можна в `js/app.js`, список `AUTHORS`.)

## Як встановити SafeLex і де він працює

**Адреса:** https://glebzelinskyi.github.io/safelex/

SafeLex — це веб-застосунок (PWA): він не завантажується з Google Play чи App Store,
а встановлюється прямо з сайту. Після встановлення має власну іконку й відкривається на весь екран,
як звичайний застосунок.

**Android (Chrome):** відкрийте адресу → кнопка «Встановити» в картці на головній
(або меню ⋮ → «Встановити застосунок» / «Додати на головний екран»).

**iPhone (Safari):** відкрийте адресу саме в Safari → «Поділитися» □↑ → «На екран „Додому“» → «Додати».

**Комп'ютер (Chrome або Edge):** відкрийте адресу → іконка встановлення праворуч в адресному рядку
(або меню → «Встановити SafeLex»). Можна й просто користуватися в браузері.

**Інтернет:** застосунок працює з будь-яким інтернетом — Wi-Fi, мобільним, університетським —
і **повністю без інтернету**. Достатньо один раз відкрити його з інтернетом: усі терміни, картинки
й шрифти збережуться в пам'яті пристрою. Далі можна вмикати режим «У літаку» — пошук, довідник
і тренажер працюватимуть. Якщо зв'язок слабкий, застосунок чекає мережу не довше 3 секунд
і відкривається з пам'яті. Коли інтернет з'являється, нові терміни підтягуються самі.

## 1. Що в папці

```
safelex/
├── index.html            ← головна сторінка (екран завантаження + нижнє меню)
├── css/style.css         ← увесь дизайн (кольори — на самому початку файлу)
├── css/fonts.css         ← підключення шрифтів
├── fonts/                ← шрифти всередині додатка (щоб працювали без інтернету)
├── js/app.js             ← логіка: пошук, екрани, тренажер
├── data/terms.js         ← ★ БАЗА ТЕРМІНІВ (14 тем) — тут ви додаєте слова
├── manifest.webmanifest  ← назва та іконка для встановлення на телефон
├── sw.js                 ← робота без інтернету
└── icons/                ← іконки додатка (+ сюди можна покласти герб)
```

Здебільшого ви працюватимете лише з одним файлом: **`data/terms.js`**.

2. Розпакуйте архів `safelex.zip` у зручне місце, наприклад `Документи/safelex`.

## 3. Як додати новий термін

База — **3353 терміни у 14 темах** зі «Словника Шуневича 2016» (англо-український словник з пожежної безпеки, літери A–C).
308 термінів позначені як **ключові** (`core: true`): тренажер дає їх першими, з них обирається «Термін дня»,
а в тренажері є окремий фільтр «Ключові».

1. Відкрийте файл **`data/terms.js`**.
2. Знайдіть потрібну тему (масив `TOPICS`, кожна тема починається з `id: "..."`, наприклад `id: "water"`).
3. Допишіть новий рядок у її масив `terms`:

```js
      { en: "stretcher", ua: "ноші", core: true,
        ex: ["Bring the stretcher to the casualty.",
             "Принесіть ноші до постраждалого."] },
```

4. Збережіть файл (Ctrl+S). Термін одразу з’явиться в пошуку, довіднику й тренажері.

**Поля терміна:**

| Поле   | Що це | Обов’язкове |
|--------|-------|-------------|
| `en`   | термін англійською. `[ ]` — варіант, що замінює попереднє слово: `flame [flaming] combustion`; `( )` — необов’язкова частина: `foam(ing) agent` | так |
| `ua`   | переклад. Різні значення — через `;` (на картці терміна вони показуються списком, у тестах — лише перше) | так |
| `ex`   | приклад: `["речення англійською", "переклад"]`. З нього тренажер робить питання «Заповніть пропуск» | бажано |
| `core` | `true` — ключовий термін | ні |
| `syn`  | інше написання: `["adaptor"]` — знаходиться пошуком і зараховується в тесті | ні |

`id` терміна створюється **автоматично** з англійського слова (`fire alarm` → `fire-alarm`), тож обране й прогрес не зламаються, коли ви додаєте нові слова.
Не змінюйте `en` уже наявних термінів без потреби — разом з ним зміниться `id`, і прогрес саме цього терміна почнеться заново.

У тренажері зараховуються всі варіанти написання: для `foam(ing) agent` правильні і *foaming agent*, і *foam agent*;
для `behavio(u)r` — і *behavior*, і *behaviour*.

**Теми (`id`):**

| id              | Назва                                    | Терміни |
|-----------------|------------------------------------------|--------:|
| `service`       | Пожежна служба та організація            | 199 |
| `alarm`         | Сигналізація, виклик і зв'язок           | 134 |
| `combustion`    | Горіння та розвиток пожежі               | 315 |
| `extinguishing` | Гасіння пожеж і вогнегасні речовини      | 145 |
| `water`         | Водопостачання, рукави та помпи          | 171 |
| `vehicles`      | Пожежна техніка та інструмент            | 105 |
| `rescue`        | Рятування, захист і допомога             | 114 |
| `buildings`     | Будівлі, конструкції та вогнестійкість   | 279 |
| `explosives`    | Вибухи та вибухові речовини              | 104 |
| `chemistry`     | Речовини, матеріали та хімія             | 330 |
| `aviation`      | Авіація, транспорт і пальне              | 118 |
| `forest`        | Лісові та природні пожежі                | 57 |
| `heat`          | Тепло і теплообмін                       | 207 |
| `technical`     | Загальнотехнічна лексика                 | 1075 |

**Правила, щоб нічого не зламалось:**
- текст завжди в подвійних лапках `"..."`;
- апостроф пишіть як `’` (пов’язка, зв’язок). Звичайний `'` теж працює, але `’` правильніший;
- між термінами обов’язково кома;
- той самий англійський термін двічі в одній темі не додавайте.

**Якщо після змін додаток порожній** — це майже завжди пропущена кома, дужка або лапка.
Натисніть F12 → вкладка **Console**: там буде назва файлу й номер рядка з помилкою.

### Багато термінів одразу (з Excel)
Якщо у вас таблиця на 100+ слів, надішліть її мені (Claude). Я перетворю її у формат `terms.js`, і вам лишиться тільки замінити файл.

### Нова тема
Скопіюйте в `terms.js` будь-який блок теми `{ id: ..., terms: [ ... ] },` і змініть:
```js
  {
    id: "demining",                         // латиницею, без пробілів
    ua: "Гуманітарне розмінування",         // назва в довіднику
    short: "Розмінування",                  // коротка назва для кнопок-фільтрів (можна не писати)
    en: "Humanitarian Demining",
    icon: "💣",                             // зараз у довіднику не показується
    desc: "Вибухонебезпечні предмети, обстеження, маркування.",
    terms: [
      /* терміни */
    ]
  },
```

У довіднику розділи згруповані (список `GROUPS` у `js/app.js`): допишіть `id` нової теми в потрібну групу,
інакше вона з’явиться в групі «Інше».

### Нове джерело
Угорі `terms.js` є список `SOURCES`. Додайте туди джерело і вкажіть його в темі (`src: "назва"`) або в окремому терміні.
Назва джерела показується на картці терміна і в розділі «Про додаток».

## 4. Що ще можна змінити

- **Герб ДСНС і логотип ЛДУ БЖД** лежать у папці `icons/`:
  `emblem.png` (герб ДСНС), `ldubzhd-logo.png` (кольоровий), `ldubzhd-logo-white.png` (білий, для темного фону), `ldubzhd-crest.png` (лише герб без напису).
  Щоб замінити, покладіть новий файл з тією самою назвою.
- **Підпис кафедри** на екрані завантаження — в `index.html`; на головній і в розділі «Про додаток» — в `js/app.js` (функції `devCard` і `renderAbout`).
- **Кольори:** `css/style.css`, блок `:root` на самому початку (`--navy`, `--accent` тощо).
- **Налаштування навчання** — `js/app.js`, блок «НАВЧАННЯ» на початку: `QUIZ_LEN` (питань у тесті), `DAILY_LEN` (у завданні дня),
  `CARDS_LEN` (карток у колоді), `MATCH_ROUNDS`/`MATCH_PAIRS` (пари), `SPRINT_SEC` (спринт). Звання — список `RANKS` у блоці «СЕРІЯ ДНІВ І ЗВАННЯ».

### Як влаштований додаток (4 вкладки)
- **Пошук** — рядок пошуку і картка **«Завдання дня»**: 10 питань усіх типів урозкид з усіх розділів.
  Пошук розумний (той самий і у фільтрі довідника): слова в будь-якому порядку, форми слів («рукава» → «рукав»,
  «ladders» → «ladder»), одруківки («evacuaton»), не та розкладка клавіатури («рщыу» → «hose»), абревіатури, синоніми
  й речення-приклади. Точний збіг показується одразу з перекладом і прикладом; розділи — з кількістю збігів;
  порожнє поле пропонує нещодавні запити або приклади, що можна пошукати.
  На картці — вогник із серією днів поспіль і тиждень наперед: сьогодні, а далі — яку серію ви матимете в кожен день (зірка — день нового звання).
  Нижче — **Термін дня** (щодня інший; «Ще один» — випадковий, можна послухати вимову і зберегти) і **Нещодавні** переглянуті терміни.
  Звання — спеціальні звання служби цивільного захисту (ст. 104 Кодексу цивільного захисту, ред. 06.10.2022), погони —
  за зразками постанови КМУ від 14.02.2018 № 81 (ред. 14.01.2026). З першого дня — Курсант; далі за серію: 3 дні — Рядовий,
  10 — Сержант, 30 — Майстер-сержант, 60 — Головний майстер-сержант, 100 — Молодший лейтенант, 150 — Лейтенант,
  200 — Старший лейтенант, 300 — Капітан, 400 — Майор, 500 — Підполковник, 600 — Полковник, 700 — Генерал-майор,
  800 — Генерал-лейтенант, 900 — Генерал-полковник, 1000 — Генерал.
  Колір картки «Завдання дня» і сила анімації змінюються з довжиною серії (1, 3, 10, 30, 100 днів).
  Нове звання відкривається святковим екраном з конфеті.
- **Довідник** — розділи з прогресом, «Усі терміни А–Я». У розділі: фільтр, алфавіт (натисніть літеру), список підвантажується під час гортання.
- **Тренажер** — оберіть розділ (або «Ключові» чи «Збережені») і режим:
  - **Тест** — 10 питань, складність росте разом зі знанням терміна; помилку повторює через 3 питання.
  - **Картки** — колода з 20 карток: згадай, переверни, «Знаю / Ще вчу».
  - **Пари** — 3 раунди по 5 пар «термін — переклад» на час, з рекордом.
  - **Спринт** — 60 секунд «вірно чи ні», з рекордом.
  - **Помилки** — лише терміни, у яких ви помилялися.
- **Моє** — звання, серія, рекорд, прогрес по базі і **збережені терміни** (☆ на картці терміна) з кнопкою «Тренувати».
  - **Статистика** (кнопка вгорі в «Моє») — відповіді й точність, активність за 14 днів (торкніться стовпчика — деталі дня), календар практики по місяцях (сітка Пн–Нд, стрілки гортають місяці до року назад; під назвою місяця — скільки днів була практика; крапка — виконане завдання дня; торкніться дня — деталі під календарем),
    скільки термінів чекає на повторення, прогрес за розділами, найскладніші терміни й рекорди. Відповіді рахуються з моменту оновлення до цієї версії.

**Як рахується «вивчено»:** термін вивчено, коли ви правильно відповіли на нього в **3 різні дні** (✓ ✓ ✓).
За день зараховується одна галочка, помилка забирає одну. Тренажер сам повертає терміни на повторення: наступного дня, через 3 дні, через 10.
Статус видно на картці кожного терміна, а пояснення — у «Моє» → «Як це рахується?». Кількість днів — `MASTERED` у `js/app.js`.
Прогрес зберігається на телефоні і не зникає після оновлень.
На комп’ютері працює клавіатура: `1–4` — відповідь, `Enter` — далі, `← →` — спринт і картки, пробіл — перевернути картку.

### Якщо термінів стане дуже багато
Додаток розрахований на тисячі термінів (перевірено на 5000): пошук показує перші 50 збігів, тести й картки вибирають терміни миттєво.
Якщо якийсь термін у `terms.js` записаний з помилкою (немає `id`, `en` чи `ua`, `id` повторюється або невідомий `cat`),
додаток **пропустить лише його** і працюватиме далі, а в консолі (F12 → Console) напише, який саме термін і чому.

## 5. Як опублікувати в інтернеті (GitHub Pages, безкоштовно)

Git вивчати не потрібно, все робиться через сайт.

1. Зареєструйтеся на https://github.com
2. Праворуч угорі **+ → New repository**. Назва: `safelex`, тип **Public** → **Create repository**.
3. На сторінці репозиторію натисніть **uploading an existing file**.
4. Перетягніть у вікно **весь вміст** папки `safelex` (самі файли й папки `css`, `js`, `data`, `icons`, а не папку `safelex` цілком) → **Commit changes**.
5. **Settings → Pages** → у полі *Branch* виберіть `main` і `/ (root)` → **Save**.
6. Через 1–2 хвилини додаток буде доступний за адресою
   **`https://ВАШ-НІК.github.io/safelex/`**

**Оновлення (приходять на телефони автоматично):**
змінили `terms.js` → на GitHub відкрийте папку `data` → **Add file → Upload files** → перетягніть новий `terms.js` → Commit.
Так само з будь-яким іншим файлом (`app.js`, `style.css`…) — завантажуйте його у відповідну папку.

Що відбувається на телефоні (Android і iPhone однаково):
- при кожному запуску з інтернетом додаток бере найсвіжіші файли з сервера;
- додаток **ніколи не перезавантажується сам**: якщо він просто висів у фоні (iPhone так робить днями), нові терміни з'являться при наступному запуску;
- при слабкому зв'язку чекає мережу не довше 3 с, далі відкривається з пам'яті;
- якщо змінився `sw.js`, зверху з'являється плашка «Є оновлення» — оновлення застосовується, лише коли користувач її натисне;
- без інтернету працює остання збережена версія.

Перевстановлювати додаток користувачам **не потрібно**. Зміни доходять протягом 1–2 хв після Commit (стільки GitHub Pages публікує сайт).

Єдиний ручний крок: якщо ви додали **нові файли** (картинки тощо), допишіть їх у список `ASSETS` у `sw.js` і збільште там `VERSION` на 1. Тоді вони працюватимуть офлайн навіть на телефонах, де їх ще жодного разу не відкривали.

**QR-код для комісії:** відкрийте адресу в Chrome → кнопка «Поділитися» в адресному рядку → **QR-код** → Завантажити.

## 6. Телефон: перевірка, встановлення, Google Play

### Що вже зроблено саме для телефона
- Встановлення на екран «Додому» з іконкою SL; відкривається на весь екран, як звичайний застосунок.
- Повна робота **без інтернету**: терміни, картинки й шрифти зберігаються в пам’яті телефона.
- Картка «Встановіть на телефон» на головній з підказкою для Android чи iPhone (у встановленому додатку не показується).
- Довге натискання на іконку → швидкі дії: **Пошук**, **Тренажер**, **Завдання дня** (Android).
- Вібрація при відповіді в тесті, свайп ← → по флеш-картках, кнопка «Пошук» на клавіатурі ховає клавіатуру.
- Кнопка «Назад» на Android працює як у звичайному застосунку.

### Як подивитися на своєму телефоні прямо зараз (без публікації)
1. Комп’ютер і телефон — в одній Wi-Fi мережі.
2. У VS Code запустіть Live Server (див. розділ 2). Внизу праворуч буде порт, зазвичай `5500`.
3. Дізнайтеся IP комп’ютера: Windows → `Win+R` → `cmd` → команда `ipconfig` → рядок **IPv4 Address** (наприклад `192.168.1.25`).
4. На телефоні відкрийте в браузері `http://192.168.1.25:5500`.

Так можна дивитися й тестувати, але **встановлення й офлайн** телефон дозволяє лише для сайтів на `https://` — для цього потрібна публікація (розділ 5).

### Встановлення (після публікації на GitHub Pages)
- **Android (Chrome):** відкрийте адресу → натисніть «Встановити» в картці на головній (або меню ⋮ → «Встановити додаток»).
- **iPhone (Safari):** «Поділитися» → «На екран „Додому“».
- **Перевірка офлайну:** відкрийте додаток один раз з інтернетом, увімкніть режим «У літаку» і запустіть знову.

### У майбутньому: справжній застосунок у Google Play
Цей самий код можна перетворити на APK/AAB для Google Play без переписування:
1. Опублікуйте додаток на GitHub Pages (розділ 5).
2. Відкрийте https://www.pwabuilder.com, вставте адресу додатка → **Package for stores → Android**.
3. Сайт згенерує готовий пакет і інструкцію, як завантажити його в Google Play Console
   (разовий внесок розробника Google — 25 $; на акаунт університету або кафедри).

Для App Store (iPhone) потрібен акаунт Apple Developer (99 $/рік) і Mac, тому для iPhone простіше лишити встановлення через Safari — воно безкоштовне і працює так само.
